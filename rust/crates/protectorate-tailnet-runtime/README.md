# protectorate-tailnet-runtime

This crate composes a joined node's pinned control-map poll, DERP and WireGuard packet engine, and userspace TCP listener and dialer. `Runtime::start(tsnet_dir, listen_port)` derives the local tailnet IP from the authenticated map; `take_accepted()` returns a bounded receiver of accepted Tokio duplex streams with authenticated peer ID and map generation. `dial_peer(name, port)` resolves one currently authorized peer and rejects identity or address changes during the TCP handshake. `State::Connected` includes the current listener address and is published only after an authenticated control map is current and the verified DERP connection has completed its handshake.

Every map-poll generation owns its own packet and TCP state. Losing the map, changing generation or local address, changing peer identity or authority, or losing the relay tears that state down. A same-generation map update without a security change is applied by the packet engine before connectivity is republished. `Authorization::current_map()` exposes only the currently applied map, and `peer_has_tag(generation, peer_id, tag)` supports per-request server admission. A failed relay connection backs off from 500 ms to 10 s. The relay must be in the local node's authenticated DERP region. Private relays require a `sha256-raw:` certificate pin; pinless public relays are limited to `derp*.tailscale.com` and use WebPKI hostname validation. The packet engine enforces peer identity, exact routes, and packet filters.

The server wires accepted streams to HTTP and owns member registration and relay lifecycle.
